# MusicDB


Проект посвящён музыкальному каталогу. База данных хранит сведения об исполнителях, их альбомах и песнях, а также о жанрах, музыкальных лейблах и продюсерах.


С помощью базы можно связать исполнителей с альбомами, а альбомы — с входящими в них песнями. Для альбома также можно указать жанр, лейбл и продюсера. Так каталог помогает хранить музыкальные записи в одном месте и не дублировать сведения об исполнителях и альбомах для каждой песни.
