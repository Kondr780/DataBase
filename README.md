# FilmDB — Система управления онлайн-кинотеатром

FilmDB — это реляционная база данных для онлайн-кинотеатра, которая охватывает предметную область управления фильмами, актёрами, жанрами, пользователями и их взаимодействиями с контентом. Система хранит информацию о фильмах (название, год выпуска, длительность, рейтинг), актёрском составе, жанровой принадлежности, а также данные о пользователях платформы и их отзывах.

Проект решает проблему структурированного хранения и эффективного поиска информации о фильмах и их метаданных. База данных позволяет отвечать на вопросы типа «Какие актёры снимались в этом фильме?», «Какие фильмы определённого жанра имеют высокий рейтинг?», «Какие пользователи оставили положительные отзывы?». Такая структура необходима для построения рекомендательных систем, фильтрации контента и аналитики пользовательского поведения.
