# CinemaDB

Проект охватывает предметную область кинематографа и каталогизации фильмов. Система решает задачу учёта фильмов, их режиссёров, актёрского состава и зрительских отзывов.

С помощью базы данных можно хранить информацию о фильмах, связывать их с режиссёрами и актёрами (один фильм — много актёров, один актёр — много фильмов), а также собирать оценки и отзывы зрителей для формирования рейтингов.
